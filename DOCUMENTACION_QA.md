# Reporte de Control de Calidad (QA) - CMS Multiinquilino

Documentación de pruebas y control de calidad para la plataforma SaaS multi-tenant de testimonios EdTech.

## 🛠️ Herramientas y Entornos de Prueba
* **Gestión de Defectos y Casos de Prueba:** Jira / Trello.
* **Pruebas de API / Backend:** Postman / Swagger.
* **Pruebas de Interfaz y Consola:** Chrome DevTools.
* **Dispositivos y Navegadores:** Chrome, Firefox y entornos responsivos móviles.

## 🧪 Estrategia de Pruebas Ejecutada
1. **Pruebas Funcionales:** Validación de flujos completos de creación, edición, aprobación y publicación de testimonios.
2. **Control de Acceso por Roles (RBAC):** Verificación de permisos y restricciones entre distintos niveles de usuarios en la arquitectura multi-tenant.
3. **Validación de API REST:** Verificación de respuestas HTTP, códigos de estado y parámetros de solicitud según la especificación de Swagger.
4. **Pruebas de Usabilidad y UI:** Inspección visual de interfaz y adaptabilidad responsiva.
5. **Gestión de Incidencias:** Documentación de hallazgos con pasos de reproducción, resultados esperados vs. obtenidos y evidencias.
